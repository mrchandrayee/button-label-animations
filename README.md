Smooth, interactive button label animations with CSS transitions and JavaScript. Pure HTML/CSS/JS microinteraction showcase.

---

## ✨ Features

- 🔘 Multiple button label transition styles
- ✨ Smooth CSS keyframe animations
- 🖱️ Hover & click interaction states
- 📱 Responsive & accessible
- ⚡ Zero dependencies
